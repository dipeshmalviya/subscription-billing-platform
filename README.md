# Subscription Billing Platform

A production-inspired subscription billing system built with Go microservices.

## Status
🚧 Work in progress — see commit history for build progress.

## Architecture
See `architecture/architecture-diagram.png`

## Services
- **Subscription Service** — GraphQL API for customers, plans, subscriptions, invoices
- **Payment Service** — gRPC service for payment processing and retries
- **Notification Service** — Kafka consumer for event-driven notifications

## Tech Stack
Go, GraphQL, gRPC, PostgreSQL, Redis, Kafka, Docker, Kubernetes
